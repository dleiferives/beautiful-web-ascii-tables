ascii-table

Add data-ascii to any <table>. The table drives column widths; the ASCII art overlays it. Select-all + copy gives you plain-text ASCII.

Use data-ascii="style-name" to pick a style. Use data-ascii-header="false" to treat all rows as data.

Custom style via JS

Register a custom style before calling .asciiTable():

$.fn.asciiTable.styles['my-style'] = {
  top:  { l:'*', f:'*', s:'*', r:'*' },
  hdr:  { l:'*', f:'-', s:'+', r:'*' },
  row:  null,
  bot:  { l:'*', f:'*', s:'*', r:'*' },
  cell: { l:'|', s:'|', r:'|' },
};
